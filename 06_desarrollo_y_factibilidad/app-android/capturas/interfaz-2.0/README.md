# Revisión de interfaz 2.0

Capturas del emulador Android de 1080 × 2400 píxeles, realizadas el 22 de septiembre de 2026. No representan una prueba con usuarios ni con el parlante físico.

- [Inicio](inicio.png): marca centrada, cuatro actividades de acceso rápido, opción libre y navegación flotante.
- [Preparación](preparacion.png): actividad seleccionada con imagen y campos ya completados, editables antes de activar el relevo.

Las fotografías completas de las siete actividades están en `app/src/main/res/drawable-nodpi/` y se usan como recursos de interfaz. La imagen no sustituye el nombre ni la acción táctil.

## Registro de cambios (disclaimer)

- **Documento nuevo:** reúne capturas reales del emulador de la versión 2.0 y explica qué muestran.
- **Antes:** la revisión visual vigente correspondía a la versión 1.9 y no incluía las actividades ilustradas.
