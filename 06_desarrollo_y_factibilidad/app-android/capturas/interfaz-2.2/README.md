# Revisión visual de la interfaz 2.2

Capturas reales del emulador Android, tomadas después de instalar el APK 2.2. No son maquetas ni sustituyen pruebas con personas.

- [Inicio](inicio.png): muestra el encabezado centrado, las actividades sugeridas, una actividad propia guardada y la navegación flotante.
- [Resumen](resumen.png): muestra la actividad propia con icono y color elegidos, el acceso a crear otra y las dos métricas de igual altura. Al desplazarse, el contenido se ve desenfocado detrás del encabezado.

La actividad «Practicar guitarra» se creó como dato de prueba en el emulador. El rendimiento del desenfoque y la accesibilidad requieren evaluación en teléfonos físicos.

## Registro de cambios (disclaimer)

- **Cambio:** se incorporaron capturas de la versión 2.2.
- **Antes:** no existía una revisión visual documentada de esta versión.
- **Motivo:** permitir comprobar las decisiones visuales con pantallas ejecutadas, no solo con descripciones.
