# Inspección visual de Android 2.7

Capturas de un emulador Android 16 de 1080 × 2400 píxeles, tomadas el 25 de septiembre de 2026 durante un recorrido con datos ficticios (secuencia 2, A → C → B, y Clock como app de ejemplo). La semana 2 y el cierre se simularon moviendo la fecha del día 0. Muestran la interfaz; no son resultados con personas.
