# Iconos

102 íconos de trazo dibujados para Relevo, en SVG de 24 × 24. Trazo de 1,75 con extremos y uniones redondeados, en tinta `#17181C`; el renglón de los íconos propios de Relevo (`actividad`, `primer-paso`, `lugar`, `parlante`, `apps`) va en `#3D38F5`. Los recortes son máscaras: funcionan sobre cualquier fondo.

Un `<img>` no cambia el color del SVG: para otro color o para el tema oscuro, usar el componente `Icon`, que dibuja el mismo trazado con `currentColor` y ajusta el grosor al tamaño.

Las versiones llenas (`inicio-lleno`, `ruta-llena`, `perfil-lleno`) son para la pestaña elegida.

## Registro de cambios (disclaimer)

### 2026-10-01 — Creación

- **Qué cambió:** se creó como parte del sistema de diseño 3.0 de Relevo, publicado en el tipo Design System de claude.ai.
- **Cómo estaba antes:** no existía; la identidad estaba en la propuesta D-098 (documento 25) y los componentes, solo en la app 2.18.
- **Por qué:** el autor pidió desarrollar y perfeccionar el sistema gráfico (comunicación, tono, colores y variantes) y pasarlo a Claude Design.
