# Exploración ampliada del sistema visual de Relevo

Esta carpeta desarrolla una biblioteca visual derivada de `Transferencia situada`. Las piezas ensayan el sistema en interfaz Android, memoria, presentación, cartel, fondos y módulos con transparencia. Cada archivo corresponde a una generación independiente; no se utilizó una lámina única para simular variedad.

## Dirección común

El lenguaje representa una intención que parte desde un campo de origen, atraviesa una relación y vuelve a hacerse perceptible mediante una señal situada. La matriz de puntos cambia de densidad y organización; no representa porcentaje, cumplimiento ni avance obligatorio. El nodo rojo se reserva para la señal situada.

Las versiones claras y oscuras comparten reglas, no una inversión automática de colores. El blanco cálido se investiga principalmente como soporte editorial. El grafito continúa como base de la interfaz digital vigente. La pantalla Android clara permanece comparativa mientras no exista una decisión que reabra el tema claro.

## Regla de uso

Las imágenes sirven como objetivos visuales para reconstrucción. No son archivos finales editables, evidencia de participantes ni especificaciones industriales. Cuando una pieza contiene texto generado, prevalece la memoria vigente; cuando contradice el contrato visual, la pieza se clasifica como material de aprendizaje y no se implementa.
