# Piezas descartadas

Esta carpeta conserva resultados que aportan aprendizaje, pero contradicen una regla vigente. No deben utilizarse como referencia de implementación sin corregir el motivo registrado.

## `cartel-transferencia-situada-oscuro-rechazado-v1.png`

La composición demuestra una transición clara desde campo a señal. Sin embargo, aplica rojo al subtítulo `TRANSFERENCIA SITUADA` y convierte el color de señal en recurso identitario general. También aumenta el nodo final hasta acercarlo a un indicador de objetivo o logro.

La pieza se conserva porque permite comparar una decisión formal atractiva con su consecuencia semántica. Una nueva versión debe mantener todo el texto en blanco o gris y limitar el rojo a un nodo pequeño.
