# Sistema editorial «Campo de evidencia»

**Estado:** dirección editorial seleccionada y en desarrollo.

Esta carpeta reúne la construcción del sistema editorial de la memoria de Relevo. La dirección seleccionada privilegia el texto académico, la evidencia y el vacío. No propone llenar cada página con recursos gráficos: utiliza una retícula constante para ordenar contenidos distintos y reserva los gestos visuales de mayor intensidad para momentos argumentales concretos.

## Fuente del contenido

El texto que se diagrame debe provenir de [`08_memoria/memoria-vigente-v4.md`](../../08_memoria/memoria-vigente-v4.md). Las imágenes de exploración sirven para estudiar composición, escala y ritmo; sus palabras, cifras y citas no forman parte de la memoria mientras no coincidan con la fuente vigente.

## Dirección aprobada

La opción «Campo de evidencia» se reconoce por:

- soporte principal blanco cálido;
- composición asimétrica y amplias zonas de descanso;
- contraste entre numerales de apertura, lectura sostenida y evidencia;
- fotografía monocromática solo cuando cumple una función documental o argumental;
- rojo reservado para una señal situada, nunca como decoración o navegación;
- matrices de puntos únicamente cuando representan información o una relación explicada.

## Estructura

- `00_direccion_y_grilla/`: fundamento, retícula canónica y reglas transversales.
- `01_referencia_seleccionada/`: imagen de dirección aprobada; no es arte final.
- `02_pruebas_con_texto_real/`: futuras páginas compuestas con contenido literal de la memoria.
- `99_descartados/`: pruebas rechazadas, con su motivo documentado.

## Condición para producir nuevas páginas

Toda página debe declarar su propósito, familia editorial, fuente textual y spans de columnas antes de incorporar recursos gráficos. Si un punto, línea, imagen o bloque no mejora la lectura o la comprensión, se elimina.
