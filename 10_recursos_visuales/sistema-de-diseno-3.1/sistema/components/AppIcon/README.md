# AppIcon

El ícono de la app: el símbolo en una caja de 512 px con esquinas de 114, centrado ópticamente.

**Qué entrega quien lo usa:** `variant` (`azul`, el principal; `tinta`; `papel`), `size` y `round` para formatos circulares.

**Android:** el grupo Logotipo trae las capas del ícono adaptable (frente con el símbolo en blanco dentro de la zona segura de 66 dp, fondo `azul-500`) y la versión monocroma para los íconos temáticos; el ícono de notificación es la silueta blanca del símbolo.

**Por qué azul:** es el único lugar donde el azul llena una superficie de la app, porque el ícono es la pantalla desde la que se prepara el relevo.

Componente de 3.1: no existe en la app 2.18; se dibujó para el sistema y su construcción está en la sección Logotipo.

## Registro de cambios (disclaimer)

- **Qué cambió:** componente nuevo de 3.1 (AppIcon).
