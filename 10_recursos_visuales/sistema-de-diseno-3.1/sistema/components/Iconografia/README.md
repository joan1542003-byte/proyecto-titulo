# Iconografia

Página de los 33 íconos nuevos de 3.1, en vivo con `Icon`: lugares, actividades, el testigo y los ámbitos. El kit completo tiene 135 íconos; los SVG están en el grupo de recursos Iconos.

## Registro de cambios (disclaimer)

### 2026-10-02 — Sistema 3.1

- **Qué cambió:** página de muestra nueva (Iconografia) con sus razones.
- **Cómo estaba antes:** no existía.
- **Por qué:** el autor pidió el 1 de octubre seguir con iconografía, tipografías y diseños, con muchos recursos argumentados en la memoria o en principios de diseño, un logotipo y una selección tipográfica cuidados, y libertad para usar más de un color.
