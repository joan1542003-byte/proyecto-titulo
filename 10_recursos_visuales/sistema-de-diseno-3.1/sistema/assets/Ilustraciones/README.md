# Ilustraciones

Seis escenas de 640 × 480, una por categoría: el lugar donde empieza una actividad, sin personas, con el parlante junto al primer paso. Trazo en tinta `#17181C`; rellenos, suelo y trama en la familia de la categoría; el fondo es el 50 de esa familia.

- `leer-sillon.svg` — mostaza. `crear-mesa.svg` — arcilla. `cuidar-ventana.svg` — salvia.
- `moverme-puerta.svg` — terracota. `compartir-juego.svg` — ciruela. `aprender-escritorio.svg` — pizarra.

Para afiches, presentaciones, la memoria y estados vacíos. La app sigue usando fotos para las ideas.

## Registro de cambios (disclaimer)

### 2026-10-02 — Sistema 3.1
