# Movimiento

- `logo-animado.mp4` — el logotipo se escribe sobre su renglón y el renglón pasa la «o»; con la firma sonora de dos notas (587 → 440 Hz, D-071). 1920 × 1080, 30 cuadros, 4 s, H.264 y AAC.
- `logo-animado-cuadro-final.png` — el último cuadro, para usar como imagen fija o cuando se pide menos movimiento.

La firma sonora sola (WAV) está en el repositorio, con el generador.
