# Iconos

135 íconos de trazo dibujados para Relevo, en SVG de 24 × 24: los 102 de 3.0 y 33 nuevos de 3.1 (lugares, actividades, el testigo y los ámbitos). Trazo de 1,75 con extremos y uniones redondeados, en tinta `#17181C`; el renglón de los íconos propios de Relevo (`actividad`, `primer-paso`, `lugar`, `parlante`, `apps`) y el suelo de los íconos de lugar (`puerta`, `cama`, `velador`, `escritorio`, `mesa`, `sillon`, `estante`, `cocina`, `ventana`, `mochila`, `canasto`) van en `#3D38F5`. Los recortes son máscaras: funcionan sobre cualquier fondo.

Un `<img>` no cambia el color del SVG: para otro color o para el tema oscuro, usar el componente `Icon`, que dibuja el mismo trazado con `currentColor` y ajusta el grosor al tamaño.

Las versiones llenas (`inicio-lleno`, `ruta-llena`, `perfil-lleno`) son para la pestaña elegida.
