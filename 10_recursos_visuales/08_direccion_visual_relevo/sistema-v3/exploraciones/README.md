## Auditoría breve

### Aportes

- ambos temas conservan jerarquía, tipografía y gramática;
- Android ya no reproduce la estructura del visor HTML;
- la memoria se presenta como familia y no como una sola portada;
- el tema oscuro tiene una función digital concreta;
- las láminas permiten reconstrucción en Figma mediante medidas documentadas.

### Límites

- los textos pequeños dentro de las imágenes pueden contener errores y no deben copiarse;
- las fotografías del objeto son representaciones exploratorias;
- la interfaz aún no cubre visualmente todas las variantes de los 35 estados;
- los archivos no demuestran accesibilidad, comprensión ni viabilidad técnica;
- la fuente generada fue ampliada a 3840 × 2160 px mediante remuestreo Lanczos; es un lienzo 4K para presentación, no un aumento real del detalle original.

## Criterio de uso

Las láminas orientan reconstrucción y comparación. Los valores normativos están en los archivos Markdown y en `tokens.tokens.json`; si una imagen contradice la especificación escrita, prevalece la especificación hasta registrar una nueva decisión.
