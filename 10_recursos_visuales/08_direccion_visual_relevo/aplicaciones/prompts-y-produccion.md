# Producción de las aplicaciones visuales

## Entradas

Las tres generaciones utilizaron como referencia directa `../exploraciones/direccion-seleccionada-v2-sistema-modular.png`. La aplicación también utilizó tres wireframes vigentes: formular, situar y recibir el pulso situado.

## Prompts resumidos

### Objeto

Se solicitó explorar cuatro familias físicas sin pantalla ni silueta definitiva. Cada forma debía expresar campo, vínculo y señal mediante perforación, difusión o materialidad, evitando asociaciones directas con alarmas, altavoces o dispositivos médicos.

### Memoria

Se solicitó aplicar el sistema a portada, apertura, texto continuo, diagrama, recorrido, figura y tabla. La tipografía matricial quedó restringida a marca, numerales y acentos; el cuerpo debía conservar jerarquía académica y estructura compatible con APA 7.

### Aplicación

Se solicitaron tres momentos del flujo existente sin alterar acciones ni información. La matriz debía funcionar como lenguaje de estado secundario; el contenido funcional debía usar texto legible, controles claros y acciones principales únicas.

## Control de calidad

Se revisaron recorte, jerarquía, consistencia cromática, ortografía de textos principales, ausencia de pantalla física, diferenciación entre soportes y correspondencia con el flujo documentado. La auditoría específica se conserva en [auditoria-piezas.md](auditoria-piezas.md).
