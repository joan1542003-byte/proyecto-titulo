# Propuesta phygital

## Propósito

Traducir investigación y evidencia de usuarios a una propuesta coherente donde la capa física, la capa digital y el lugar tengan funciones explícitas.

## Documentos previstos

- propuesta de valor y razones de existencia;
- requisitos y no requisitos;
- arquitectura del sistema;
- flujo del usuario;
- flujo técnico;
- flujo de diseño y producción;
- estados, errores y casos límite;
- alternativas consideradas y criterios de selección;
- lenguaje formal, material y sensorial;
- privacidad, autonomía y accesibilidad.

## Pregunta de control

Si una función puede resolverse de igual manera mediante una notificación convencional, debe justificarse por qué requiere un objeto físico. La condición phygital no puede ser decorativa.
