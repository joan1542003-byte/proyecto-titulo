# Medios históricos de la memoria E12 de In(Visible)

## Propósito

Esta carpeta restaura dos figuras propias que la memoria E12 ya enlazaba, pero que no habían sido incorporadas durante la primera migración. Se conservan para evitar una lectura incompleta del antecedente In(Visible).

Las figuras describen una formulación reemplazada. No constituyen usuarios vigentes, arquitectura vigente ni visualidad que deba continuar en la entrega actual.
