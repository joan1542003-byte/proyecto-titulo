# Feedback del examen E15

## Propósito

Esta colección conserva únicamente el bloque de feedback correspondiente a Relevo dentro de un documento colectivo. Separa el registro histórico de las decisiones vigentes y evita que una sugerencia de la evaluación se transforme automáticamente en una definición del proyecto.

## Fuente

- **ID:** F-002.
- **Archivo:** `Encargo 15_Examen.docx`.
- **Naturaleza:** documento colectivo de feedback académico.
- **Bloque pertinente:** páginas renderizadas 44–49.
- **Cobertura publicada:** solo el contenido asociado a Johan Yantén y Relevo.
- **Original:** conservado de forma privada fuera del repositorio.

## Documentos

1. [Registro normalizado](registro-normalizado.md): conserva las notas directas, la síntesis estructurada y la deliberación como capas distintas.
2. [Matriz de trazabilidad](matriz-de-trazabilidad.md): transforma las observaciones en preguntas, tareas o exclusiones con estado explícito.
3. [Informe de integridad](informe-de-integridad-docx.md): documenta estructura, revisión visual, comentarios, límites y omisiones.
4. [Síntesis activa](../../../../../01_contexto_y_fuentes/feedback-e15.md): reúne únicamente los aprendizajes utilizables por el proyecto actual.

## Jerarquía de lectura

1. Las notas atribuidas directamente a cada evaluador son la capa principal del feedback.
2. Los apartados denominados `Feedback estructurado` son una síntesis contenida en la fuente, no una transcripción literal de la comisión.
3. La deliberación y el veredicto se conservan como registro histórico, pero no sustentan decisiones de diseño por sí solos.
4. La matriz formula pendientes; no declara resueltos aspectos que aún necesitan investigación.
5. La solicitud actual del autor y la evidencia del proyecto prevalecen ante cualquier tensión con el documento histórico.

## Decisiones de archivo

- Se normalizó el nombre `Yohan` como `Johan`.
- Se corrigieron ortografía y puntuación cuando el sentido era inequívoco.
- No se incorporó contenido de otros estudiantes.
- No se subieron el DOCX, sus dos comentarios ajenos al bloque ni los sesenta renders de control.
- El ejemplo de sedentarismo se conserva como sugerencia y no como dirección adoptada.
- Las apreciaciones personales sobre el estudiante no se trasladan a la memoria ni se usan como evidencia del problema.
- La ausencia de visualidad en la entrega actual no elimina la necesidad futura de documentar flujos; solo cambia su prioridad de producción.
