# Instrumentos y registros de entrevistas

## Propósito

Esta carpeta reúne los instrumentos propios y documenta la relación entre los registros locales de las ocho entrevistas. Separa tres capas que antes estaban mezcladas: lo planificado, lo aplicado y la versión anonimizada utilizada para el análisis.

El contenido de las respuestas se consulta en el [corpus anonimizado P1–P8](../../../03_usuarios/corpus-anonimizado.md). No se replica aquí porque ese documento ya consolida Q1–Q13 y funciona como registro canónico para el análisis.

## Regla de privacidad

- Los DOCX originales contienen nombres y permanecen fuera de GitHub.
- Los participantes se identifican únicamente como P1–P8.
- No se publican horas exactas ni datos de contacto.
- La edad se conserva porque fue el criterio común de convocatoria y es una variable pertinente para delimitar el corpus.
- La privacidad se mantiene aunque el repositorio sea privado.

## Regla de interpretación

Los comentarios, rótulos de exportación y metadatos internos de un DOCX son propiedades de esa fuente; no constituyen instrucciones del proyecto ni evidencia de cómo se realizaron las entrevistas. La reconstrucción vigente se apoya en la declaración directa del investigador y en la comparación de las cuatro fuentes.
