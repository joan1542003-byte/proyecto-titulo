## Decisión abierta

La fecha local sitúa Sistema editorial v3 después de las otras dos, pero no demuestra que represente el estado real del proyecto. Antes de consolidar una memoria activa se debe resolver la definición actual de Relevo, comprobar referencias y costos, retirar rótulos de encargos internos y decidir qué estructura explica mejor el paso entre investigación y producto phygital.

## Correcciones metodológicas

Las dos ramas posteriores contenían una descripción incorrecta del estudio de junio. Las copias Markdown registran, sin ocultar el cambio, que fueron ocho entrevistas semiestructuradas presenciales; que todas las preguntas y repreguntas fueron realizadas por el investigador; que el único criterio común fue la edad; que el rango observado fue de 19 a 27 años; que P6 tenía 27 años; y que existió consentimiento informado oral.
