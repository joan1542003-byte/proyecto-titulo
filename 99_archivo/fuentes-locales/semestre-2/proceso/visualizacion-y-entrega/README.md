## Registro de cambios (disclaimer)

### 2026-08-23 — Creación

- **Cambio:** se creó un índice funcional para documentación histórica ya existente.
- **Versión anterior:** los archivos estaban repartidos entre paquetes de entrega y copias de exportación.
- **Motivo:** permitir navegación por función y separar antecedentes de contenido vigente.
- **Alcance:** el índice no reactiva la visualidad ni valida perfiles, mapas o flujos.
