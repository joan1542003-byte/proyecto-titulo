# Encargo 16 · Diagramas de flujo funcional

Se produjeron tres Mapas 2, uno por cada perfil sintético. Cada diagrama representa la experiencia de la persona, no la arquitectura técnica: intención, primer paso, ubicación, prueba de la señal, condición, decisión y cierre.

La sintaxis utiliza el vocabulario visual de Garrett: procesos rectangulares, decisiones en rombo, inicio/fin redondeados y conectores con dirección explícita. No se incorporan permisos, Bluetooth, sensores ni componentes internos; esos elementos pertenecen al Mapa 3.

Todos los resultados siguen siendo hipótesis de validación. El cierre no registra cumplimiento: la persona puede actuar, silenciar la señal o ignorarla.
