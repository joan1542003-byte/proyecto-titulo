Esta carpeta organiza el desarrollo de Relevo durante el segundo semestre. La migración se realiza por familias documentales y no por el orden de las carpetas locales, porque allí conviven fuentes editables, exportaciones, duplicados, ramas denominadas final y materiales institucionales.

## Regla de trabajo

La familia de memorias y los 21 Markdown de proceso ya fueron organizados. La siguiente unidad debe revisar documentos propios de otros hitos y equivalencias PDF/DOCX; no se reanuda todavía el desarrollo de usuarios ni se declara una dirección formal.
