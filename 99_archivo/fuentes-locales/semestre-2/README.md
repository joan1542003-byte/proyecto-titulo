# Archivo documental del semestre 2

## Propósito

Esta carpeta organiza el desarrollo de Relevo durante el segundo semestre. La migración se realiza por familias documentales y no por el orden de las carpetas locales, porque allí conviven fuentes editables, exportaciones, duplicados, ramas denominadas final y materiales institucionales.

## Regla de trabajo

La familia de memorias se resolvió primero porque concentra la formulación más amplia del proyecto. La siguiente familia será la documentación Markdown ya existente. No se reanuda todavía el desarrollo de usuarios ni se declara una dirección formal.
