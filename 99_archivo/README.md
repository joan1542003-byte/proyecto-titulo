# Archivo histórico

## Propósito

Conservar materiales superados o exploratorios sin tratarlos como formulación vigente ni eliminarlos del proceso.

## Puede contener

- síntesis de versiones anteriores;
- perfiles hipotéticos;
- propuestas descartadas;
- diagramas reemplazados;
- decisiones abandonadas;
- extractos anonimizados de documentos derivados;
- índices de archivos locales que no se suben por privacidad.

## Regla de archivo

Todo elemento archivado debe indicar:

- de qué etapa proviene;
- por qué dejó de estar vigente;
- qué aprendizaje se conserva;
- qué documento o decisión lo reemplazó.

El archivo no es una papelera. Su función es preservar la evolución del proyecto sin contaminar los documentos activos.
