# Usuarios

## Propósito

Comprender comportamientos, necesidades, dolores, deseos, experiencias y límites de intervención antes de construir perfiles o recorridos.

## Secuencia obligatoria

1. Auditar el instrumento y la muestra.
2. Anonimizar las respuestas válidas como P1–P8.
3. Crear una matriz de evidencia por participante.
4. Codificar patrones y casos contrastantes.
5. Distinguir usuario potencial, usuario límite y no usuario.
6. Identificar vacíos y, si corresponde, realizar nuevas entrevistas.
7. Formular dos tipos de usuario provisionales.
8. Construir personas únicamente con atributos respaldados.
9. Desarrollar recorridos actuales y escenarios futuros.
10. Traducir los resultados a requisitos y criterios de exclusión del producto.

## Restricciones actuales

- Los tres perfiles ficticios existentes no se reutilizarán como resultados.
- No se publicarán nombres ni citas identificables.
- Las preguntas adicionales sobre reacción al objeto no se usarán hasta aclarar su procedencia.
- Ocho respuestas no permiten hablar de segmentos representativos del mercado.
- Todavía debe decidirse si los dos tipos solicitados serán:
  - usuario principal y usuario límite; o
  - dos variaciones dentro del público objetivo.
