# Decisiones

Este directorio registra elecciones que afectan el alcance, método o producto. Su objetivo es conservar por qué se tomó una decisión, qué alternativas se descartaron y qué evidencia podría obligar a revisarla.

## Formato mínimo

- identificador;
- fecha;
- estado;
- pregunta;
- decisión;
- fundamento;
- alternativas;
- consecuencias;
- condición de revisión;
- fuentes relacionadas.

El registro principal está en `registro-de-decisiones.md`.
