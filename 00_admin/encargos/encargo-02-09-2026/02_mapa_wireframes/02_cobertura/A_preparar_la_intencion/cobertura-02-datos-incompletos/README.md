# Estado 02 — Datos incompletos

![Wireframe del estado 02 — Datos incompletos](wireframe.png)

## Qué resuelve

Señala qué falta sin borrar lo ya escrito. Permite corregir o guardar un borrador.

## Qué puede ocurrir después

Completar, revisar permisos o pasar a revisión.

Este estado forma parte de la cobertura del sistema. Aparece solo cuando se cumple su condición y no agrega un paso obligatorio a la ruta principal.
