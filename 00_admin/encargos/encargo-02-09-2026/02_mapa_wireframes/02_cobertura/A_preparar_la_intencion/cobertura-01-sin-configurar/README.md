# Estado 01 — Sin configurar

![Wireframe del estado 01 — Sin configurar](wireframe.png)

## Qué resuelve

Define el punto de partida cuando no hay ciclo. Evita mostrar datos, progreso o acciones que todavía no corresponden.

## Qué puede ocurrir después

Crear una intención o permanecer inactivo.

Este estado forma parte de la cobertura del sistema. Aparece solo cuando se cumple su condición y no agrega un paso obligatorio a la ruta principal.
