# Estado 11 — Probar lugar

![Wireframe del estado 11 — Probar lugar](wireframe.png)

## Qué resuelve

Relaciona el testigo con el primer paso y abre la prueba situada.

## Qué puede ocurrir después

Emitir el pulso, ajustar o cambiar el lugar.

Este estado forma parte de la cobertura del sistema. Aparece solo cuando se cumple su condición y no agrega un paso obligatorio a la ruta principal.
