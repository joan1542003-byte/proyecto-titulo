# Estado 13 — Señal intrusiva

![Wireframe del estado 13 — Señal intrusiva](wireframe.png)

## Qué resuelve

Permite reducir o reubicar una señal que interfiere con el contexto.

## Qué puede ocurrir después

Ajustar, cambiar el lugar o no armar.

Este estado forma parte de la cobertura del sistema. Aparece solo cuando se cumple su condición y no agrega un paso obligatorio a la ruta principal.
