# Referencias visuales rescatadas

Esta carpeta reúne cuatro exploraciones que no tenían una copia exacta dentro del repositorio y que todavía aportan decisiones gráficas útiles. Se conservan como **referencias de proceso**, no como páginas finales de la memoria.

## Piezas

### 01. Estado del arte y matriz

Explora una doble página clara con comparación de referentes. Es útil por la jerarquía entre introducción, matriz y casos, pero su contenido debe reemplazarse por datos y citas verificadas antes de publicarse.

### 02. Planteamiento y tres aristas

Ensaya una apertura oscura donde las aristas convergen visualmente. Aporta una forma de explicar relaciones complejas sin llenar la página de recursos decorativos.

### 03. Usuario y contexto

Prueba la combinación entre hallazgos, citas breves y fotografía monocromática. La imagen funciona como referencia de composición; no debe presentarse como registro documental de las entrevistas.

### 04. Cartel “Señal, no alarma”

Explora una pieza gráfica de síntesis mediante tipografía, campo de puntos y un único acento rojo. El texto es provisional y debe revisarse antes de cualquier uso público.

## Criterio de rescate

Se copiaron únicamente piezas con valor compositivo o metodológico. No se incorporaron una primera versión defectuosa de la pantalla principal ni dos editoriales cuyo contenido se alejaba del proyecto vigente. Las imágenes con transparencia no se duplicaron aquí porque las 25 ya están respaldadas dentro de `10_recursos_visuales`.
