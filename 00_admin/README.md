# Administración del repositorio

Esta carpeta reúne las entregas organizadas por fecha y los controles que ayudan a revisarlas. No reemplaza las áreas de investigación, propuesta, desarrollo o memoria: funciona como un punto de acceso administrativo para presentaciones y respaldos concretos.

## Cómo orientarse

1. Para conocer el estado general del proyecto, comenzar por el [README principal](../README.md).
2. Para conocer la estructura y la fuente vigente de cada área, revisar el [índice operativo](../00_gobernanza/indice-del-repositorio.md).
3. Para revisar una entrega específica, entrar a [encargos](encargos/README.md) y seguir el README de la fecha correspondiente.

## Contenido actual

- [Encargos y entregas fechadas](encargos/README.md): copias preparadas para revisión, separadas por resultado, documentación de apoyo y referencias.

## Regla de organización

Una entrega fechada puede reunir copias de archivos que también existen en un área de trabajo. La copia administrativa facilita la revisión de ese momento; el README de cada entrega indica cuál es su fuente vigente, qué material funciona como respaldo y qué elementos son históricos.

Las decisiones de investigación y diseño deben registrarse en sus áreas temáticas y en `09_decisiones`. Las tareas y sus criterios de cierre se controlan mediante GitHub Issues. Las carpetas auxiliares locales que no estén rastreadas por Git no forman parte del repositorio publicado.
